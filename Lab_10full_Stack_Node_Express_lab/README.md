## ⚙️ Setup Instructions

### 1. Install Node.js
Download from: https://nodejs.org/en/download (LTS version)

Verify:
```bash
node -v
npm -v
```

### 2. Install Dependencies
```bash
npm install
```

---

## 🚀 Running Each Task

Each task runs on its own port. Open a new terminal for each.

### Task 1 — Student List Display
```bash
node task1_student_list.js
```
Open: http://localhost:3001/students

### Task 2 — Simple Message Routes System
```bash
node task2_message_routes.js
```
Open:
- http://localhost:3002/home
- http://localhost:3002/about
- http://localhost:3002/contact

### Task 3 — Dynamic User Page
```bash
node task3_dynamic_user.js
```
Open: http://localhost:3003/user/Ali  
(Replace Ali with any name)

### Task 4 — Simple HTML Page Renderer
```bash
node task4_html_renderer.js
```
Open: http://localhost:3004
